🎟️ Universal Ticket Management System
🇹🇷 TÜRKÇE

Universal Ticket Management, konser, tiyatro ve stadyum gibi etkinlik alanları için tasarlanmış, uçtan uca çalışan profesyonel bir bilet satış ve koltuk yönetim otomasyonudur. Arka planda güçlü bir .NET Core Web API mimarisi kullanırken, ön yüzde React ve modern CSS animasyonları ile akıcı ve premium bir kullanıcı deneyimi sunar.

🚀 Öne Çıkan Özellikler & Çözümler
Neon Rezervasyon Sayacı: Bilet seçiminde devreye giren, son 1 dakikada "pulse" animasyonu ile kullanıcıyı uyaran, React tabanlı dinamik 5 dakikalık geri sayım sistemi.

Admin Afiş Yönetimi: Kod tarafına müdahale etmeden, admin panelinden anlık afiş (banner) yükleme imkanı. LocalStorage entegrasyonu sayesinde yüklenen görseller tarayıcı hafızasında kalıcı hale getirilir.

Akıllı İndirim & Fiyatlandırma: YAZ20 veya REACT50 gibi kupon kodlarıyla anlık çalışan, eski fiyatın üstünü çizip indirimli tutarı altın sarısı efektlerle patlatan dinamik hesaplama motoru.

Premium 3D Sahne Deneyimi: Klasik düz çizgiler yerine, gerçek amfitiyatro hissi veren kavisli, gölgelendirilmiş ve spot ışığı efektli 3 boyutlu sahne tasarımı.

Gelişmiş Koltuk Kategorizasyonu: VIP ve Standart koltuk ayrımı, gerçek zamanlı doluluk takibi ve tek tıkla sepeti boşaltan "Hızlı İptal" (X) mekanizması.

Persistent Data UI: Sayfa yenilense bile seçili tercihleri ve yüklenen görselleri koruyan kullanıcı dostu veri yönetim yapısı.

🛠️ Kullanılan Teknolojiler
Backend: C# ASP.NET Core 8 Web API, Entity Framework Core.

Frontend: React.js, Vite, CSS3 (Advanced Animations & Flexbox).

Database: MS SQL Server / In-Memory Database.

🇬🇧 ENGLISH

Universal Ticket Management is an end-to-end professional ticket sales and venue management automation platform designed for event spaces such as concerts, theaters, and stadiums. It leverages a robust .NET Core Web API architecture on the backend, while providing a fluid and premium user experience on the frontend using React and modern CSS animations.

🚀 Key Features & Solutions
Neon Reservation Timer: A React-based dynamic 5-minute countdown system that triggers during ticket selection, featuring a "pulse" animation to alert users during the final minute.

Admin Banner Management: On-the-fly banner updates via the admin panel without any code intervention. Integrated with LocalStorage to ensure uploaded visuals persist across browser sessions.

Smart Discount & Pricing Engine: A real-time calculation engine that supports promo codes like YAZ20 or REACT50, featuring strikethrough original prices and highlighted gold-tinted discounted totals.

Premium 3D Stage Experience: A curved, shaded, and spotlight-enhanced 3D stage design that provides a realistic amphitheater feel instead of basic flat lines.

Advanced Seat Categorization: Distinct VIP and Standard seat types, real-time occupancy tracking, and a "Quick Clear" (X) mechanism for instant cart management.

Persistent Data UI: A user-centric data structure that maintains selected preferences and uploaded assets even after page refreshes.

🛠️ Tech Stack
Backend: C# ASP.NET Core 10.0 Web API, Entity Framework Core.

Frontend: React.js, Vite, CSS3 (Advanced Animations & Flexbox).

Database: MS SQL Server / In-Memory Database.
